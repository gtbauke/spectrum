\section{Introdução}

Regressão simbólica é uma técnica de regressão que busca encontrar expressões matemáticas que melhor
se ajustem a um conjunto de dados, considerando tanto acurácia quanto a simplicidade da expressão.
Algoritmos considerados \textit{State of the Art} (SotA) utilizam de programação genética como principal mecanismo
de busca do espaço de soluções.
\par Esse tipo de algoritmo é muito usado nas ciências naturais para obter um melhor entendimento de fenômenos
observados. Muitas vezes, uma relação linear é assumida como boa aproximação entre as variáveis independentes e dependentes pela facilidade
na interpretação do modelo. No entanto, elas podem falhar em representar a complexidade de alguns fenômenos governados por
relações não lineares.
\par Algoritmos de regressão não lineares, muitas vezes, requerem um maior esforço computacional para encontrar uma solução
adequada, além de necessitarem de conhecimento técnico para serem corretamente utilizados e interpretados. A regressão simbólica
almeja simplificar esse processo, permitindo que relações não lineares sejam encontradas ao mesmo tempo que a simplicidade da expressão é considerada.
