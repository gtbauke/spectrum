\section{Desenvolvimento Front-end}
A construção das telas da plataforma e suas funcionalidades será realizada através do \textit{framework} React (desenvolvido e mantido pela Meta) que utiliza a linguagem imperativa \textit{JavaScript}.

\section{Desenvolvimento Back-end}
Para o desenvolvimento da \textit{API} web e dos \textit{workers} (programas especializados, nesse caso para treinamento de modelos de regressão simbólica) será utilizado o \textit{framework FastAPI}, o qual utiliza a linguagem Python. Além disso, serão utilizadas duas bibliotecas específicas para manipulação dos modelos de regressão: \textit{eggp}~\cite{eggp}, usada para treinamento dos modelos, e \textit{rEGGression}~\cite{rEGGression}, utilizada para manipular os modelos criados pela primeira biblioteca.
